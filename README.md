## Stemmi — `img/stemmi/`

Un file per club, `.png` (sfondo trasparente) oppure `.svg`:

atalanta · bologna · cagliari · como · fiorentina · frosinone · genoa · inter · juventus · lazio · lecce · milan · monza · napoli · parma · roma · sassuolo · torino · udinese · venezia

Esempio: `img/stemmi/inter.png`.

Stemmi e foto sono protetti da diritti (marchi dei club, diritti del fotografo). Prima di pubblicare usa immagini di cui hai la licenza, per esempio file di Wikimedia Commons con licenza libera e relativa attribuzione.
